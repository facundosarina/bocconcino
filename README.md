# Bocconcino

Diario alimentare con foto: scatti il piatto e Bocco stima calorie, proteine, carboidrati e grassi.
App web installabile (PWA) in italiano, español e English.

- L'analisi usa l'API gratuita di Google Gemini con la chiave personale di chi la usa (salvata solo sul telefono).
- Pasti, foto e impostazioni restano nel browser del telefono (IndexedDB); c'è un backup scaricabile.
- Nessun server, nessun account.

Apri: https://facundosarina.github.io/bocconcino/
